# Brand mark (canonical)

**Status: LOCKED** (mark 2026-11-02, favicon 2026-11-03)

**Square mark:** Ubuntu Regular `ls` + 3 amber bars on a charcoal squircle tile
- Thin stack (gap ≈ bar height, ~42px at 512)
- Corner radius **1px**
- Gap between `ls` and stack ~41px at 512
- Side margins even, ~76px at 512

**Favicon:** separate cut for browser tabs only
- Ubuntu **Bold** `ls`, same height as the main mark; bar geometry unchanged
- Mark ~20% larger than the main mark; gap `ls` to bars 38px, side pads 31/32 at 512
- Bars in lighter copper **`#d48738`** (same hue/saturation as `#c4782a`, +6 lightness) so they hold brightness when downscaled

**Files** (relative to this folder)
- `logo-512.png`: main mark master (same bytes as `icons/lsstack-512.png`)
- `icons/lsstack-{16,32,48,64,128,256}.png`: downscaled from the master
- `icons/lsstack-180.png`: iPhone `apple-touch-icon`; solid charcoal corners, iOS applies its own rounding
- `icons/lsstack-192.png`: Android / web app manifest; transparent corners
- `favicon/favicon-512.png`: favicon master
- `favicon/favicon-{16,32,48}.png` and `favicon/favicon.ico` (16/32/48)
- `fonts/Ubuntu-R.ttf`: wordmark on the landing page (Ubuntu Font Licence 1.0, `fonts/UFL.txt`)

**Color:** amber `#c4782a` · charcoal tile `#191e23` · off-white `ls` `#eceef0` · transparent outside squircle
